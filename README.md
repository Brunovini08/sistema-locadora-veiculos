# 🚗 Sistema de Locação de Veículos

Um sistema de console desenvolvido em **C#**, que permite o gerenciamento de locações de veículos — desde o cadastro de clientes e automóveis até o aluguel e devolução dos veículos.

---

## 📋 Funcionalidades

O sistema oferece as seguintes opções no menu principal:

1. **Alugar veículo**  
   Permite registrar uma nova locação, vinculando um cliente a um veículo disponível e definindo as datas de início e fim da locação.

2. **Devolver veículo**  
   Encerra uma locação ativa, atualizando o status do veículo para disponível novamente.

3. **Cadastrar veículo**  
   Adiciona novos veículos à frota, informando dados como modelo, placa, ano, e valor de diária.

4. **Listar todos veículos com base em categoria ou combustivel**  
   Exibe todos os veículos que estão livres para locação no momento.

5. **Cadastrar cliente**  
   Cadastra novos clientes no sistema, armazenando nome, CPF e outros dados relevantes.

6. **Buscar cliente**  
   Permite localizar um cliente específico pelo nome ou CPF.

7. **Listar clientes**  
   Exibe todos os clientes cadastrados.

8. **Listar locações**  
   Mostra todas as locações realizadas, com informações de cliente, veículo e datas.

0. **Sair**  
   Encerra o programa.
